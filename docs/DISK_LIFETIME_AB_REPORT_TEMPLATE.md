## 2. 配置与场景的可比性清单

每个场景保存 A=新 binary 的显式 legacy、B=同一 binary 的显式 lifetime 的
启动命令/完整环境/生效 dump。其余容量、几何、RAM、合并、并发、预算、trace、
初态、预热、热度及观察时长一致；RAM write-back 两组显式 disk ACK。现役 RAM
ACK 的迁移参考和 v2.33.0 行为组分表，不混作算法收益。

每项写场景 ID、配置/trace/初态 SHA、正式样本 ID 和覆盖状态：

- 冷启动、稳定热点、一次扫描、长前缀、首次早读与未读同池竞争。
- 混合尺寸、持续/突发写、near-full、全 pin、真实/注入 I/O 失败。
- clean 恢复 0–15 分钟、dirty、连续 clean restart、模式切换、旧冷多数与新热点。
- RAM/合并开关 × M=1/2/4/63；同逻辑 trace 的同代来源资格与通知竞争。
- 相同评分档双索引/同 now 队头、跨片 cursor、pin 长前缀与访问预算、tick 进展。
- 合法 4 KiB/目标几何、M63、全 E 粗查和大 extent 清表/sync 成本。

“已有单测”与“本次正式场景已执行”分开列。某场景不适用必须给出事前依据和独立
确认，不能为了通过删除困难场景或降低合法几何；缺必需场景则完整验收仍 open。
